- **Framework & Routing**: Built on Next.js App Router with file-system routing. Public routes use `(site)` route groups, while admin functionality is isolated under `/admin` with `force-dynamic` rendering to support runtime auth checks.
- **UI Architecture**: Implements a custom "Desktop Environment" (`src/components/os`) using React Context (`OSSystemContext`, `DesktopWindowContext`) to manage window states, z-indexes, and system overlays (Spotlight, Mission Control). It relies heavily on `framer-motion` for complex entrance animations and window transitions.
- **Admin Interface**: The admin panel (`src/app/admin`) mimics the public OS experience using a dedicated `AdminDesktopShell` and `useAdminDesktop` hook, providing a consistent windowed experience for CRUD operations.
- **API Layer**: RESTful API routes (`src/app/api`) handle data persistence, AI generation, and webhooks. Admin APIs are protected by middleware-based JWT verification and CSRF token validation.
- **State Management**: Uses a hybrid approach: React Context for UI/OS state, `@tanstack/react-query` for server-state synchronization in the admin panel, and local storage/session storage for visitor session persistence.
