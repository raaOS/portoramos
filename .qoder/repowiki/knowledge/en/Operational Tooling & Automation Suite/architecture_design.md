- **Domain-Specific Sub-packaging**: Scripts are organized into functional sub-directories (e.g., `cloudflare/`, `media/`, `job-bot/`, `performance/`) rather than a flat structure, isolating concerns like D1/R2 management from asset processing.
- **Development Orchestration Layer**: The `core/dev.js` script acts as a process supervisor, spawning the Next.js server and auxiliary services (like the Telegram job bot poller) with coordinated lifecycle management, including webhook state preservation via Cloudflare D1 leases.
- **Shared Library Integration**: Scripts frequently import internal modules from `src/lib/` (e.g., `cloudflareD1`, `r2Storage`, `jobBot/config`) to reuse configuration logic and environment validation, ensuring consistency between application code and tooling.
- **Hybrid Runtime Support**: The suite supports both JavaScript (`.js`, `.mjs`, `.cjs`) and TypeScript (`.ts`) execution, utilizing `tsx` for on-the-fly compilation of TypeScript utilities without a separate build step for the scripts themselves.
